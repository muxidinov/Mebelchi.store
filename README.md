Mebelchi.store — Furniture E-commerce Platform

A modern, responsive furniture e-commerce website designed to provide a clean shopping experience with an elegant user interface.

About the Project

Mebelchi.store is a furniture e-commerce project focused on modern design, responsive layouts, and a convenient product browsing experience.

The project is being developed to combine thoughtful UI/UX design with practical frontend development.

Key Features

• Responsive Design — designed for desktop, tablet, and mobile screens.
• Product Catalog — organized furniture categories and product listings.
• Product Details — dedicated product pages with images and specifications.
• Multilingual Interface — Uzbek and Russian language support.
• Order Workflow — planned integration with Telegram for receiving customer orders.
• Modern UI/UX — clean layouts, consistent spacing, and a focus on usability.
• Product Image Management — structured folders for easy catalog maintenance.
